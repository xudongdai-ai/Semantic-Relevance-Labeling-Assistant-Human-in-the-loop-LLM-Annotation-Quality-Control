# 后端集成边界

本公开包不包含服务专属 URL、路由或完整请求/响应协议。在线导出或提交前，需要创建本地 `annotation_routes.json`，将逻辑操作映射到你有权访问的服务路由。示例模板位于 `examples/api_routes.example.json`。

## 逻辑操作

| 逻辑操作 | 用途 |
| --- | --- |
| `login` | 使用账号凭据建立会话 |
| `session` | 确认登录态有效 |
| `project` | 读取项目元信息并核对任务类别 |
| `project_export` | 可选读取在线项目导出 |
| `item_detail` | 读取本人任务状态、Query 和已有答案 |
| `submit_item` | 提交本人审核后的答案 |

路由模板可使用 `{project_id}` 和 `{item_id}` 占位符；值只存在于本地配置中。`annotation_routes.json` 已加入 `.gitignore`。

## 数据边界

核心逻辑读取规范化的语义相关性导出记录，按账号分配关系筛选任务，对每个 Query 的 AI 等级和候选模型一致度生成 `ready` / `needs_review` 计划。连接其他后端时，应在本地适配层完成导出字段映射，不要把内部接口协议或真实任务导出提交到公开仓库。

工具不会调用模型服务；模型等级应已存在于导出数据中。提交前必须查看预览，提交后会回读并核对保存结果。
